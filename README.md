One emoji, one smile: this program writes a single 🫶 (heart hands) — two hands forming a heart, a small gesture of warmth a stranger reads instantly — to `entry.txt`, and nothing else.

## Run it

```sh
node main.ts
```

It writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
